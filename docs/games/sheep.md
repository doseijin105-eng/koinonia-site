# 迷子の羊をさがせ ― 仕様メモ

- 場所:トップページ(9言語すべて)の「#game」。スクリプトは `sheep-game.js` 1つを全言語で共有
- 聖書箇所:ルカの福音書15章(いなくなった一匹の羊のたとえ)
