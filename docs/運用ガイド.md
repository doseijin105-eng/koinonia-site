# ゲーム制作と公開の運用ガイド(Claude・ChatGPT・Gemini の連携)

2026年11月25日 作成

ChatGPT・Gemini・Claude の3つを使い分けて、聖書のゲームを作って公開するための約束ごとです。
いちばん大事なのは「**正本は GitHub の koinonia-site ひとつだけ**」ということです。

## 1. 全体の流れ

1. **相談・仕様づくり**:作りたいゲームを Claude に相談し、仕様メモ(`<ゲーム>/README.md`)を作る
2. **素材づくり**:Gemini で絵と音楽を作り、Googleドライブ「ゲーム制作(素材・管理) / <ゲーム名>」に入れる。素材管理表に記録
3. **中身づくり**:ChatGPT(Codex)か Claude がゲームを作る。ChatGPT はブランチ+プルリクエストで出す
4. **試し公開で確認**:プルリクエストに付く Netlify の試し公開URL(無料)で遊んで確かめる
5. **本番公開**:よければ Claude が本番(`main`)に取り込む。公開はまとめて週1回くらい

## 2. 役割分担

| だれ | 主にすること | 置き場所 |
|---|---|---|
| Gemini | 絵(キャラクター・背景・アイコン・エフェクト)、音楽(BGM・効果音) | Googleドライブ「ゲーム制作(素材・管理)」 |
| ChatGPT(Codex) | 新しいゲームの試作、機能の追加 | GitHub のブランチ → プルリクエスト |
| Claude | 素材の組み込み、ChatGPT の変更の確認と取り込み、ランキングなど共通のしくみ、公開と動作確認、仕様メモと素材管理表の更新 | GitHub の `main`、ドライブ |
| 新井さん | 何を作るか決める、試し公開で遊んで確かめる、公開の「よし」を出す | ― |

## 3. 置き場所

- **GitHub**:https://github.com/doseijin105-eng/koinonia-site （公開リポジトリ。ゲームの本体、仕様メモ、ルール)
- **Netlify**:koinonia-nagoya(`main` が本番、プルリクエストごとに試し公開)
- **Googleドライブ**:「自作アプリ › ゲーム制作(素材・管理)」フォルダ(ゲームごとのサブフォルダに、Gemini で作った元の絵と音楽、素材管理表、プロンプト集)
- **AI へのきまり**:リポジトリ一番上の `AGENTS.md`(ChatGPT・Claude・Gemini が読む)

## 4. Netlify のクレジット(大事)

- 無料プランは月300クレジット。本番公開1回で15クレジット(月20回くらいが上限)
- 試し公開(プルリクエスト)は無料・回数無制限
- 説明書(`.md`)と `docs/` だけを直したときは、公開しない設定にしてあります
- 使い切ると、次の月まで本番公開が止まります(サイト自体は動き続けます)。毎月5日に戻ります

## 5. ChatGPT に頼むときの例文

```
GitHub の doseijin105-eng/koinonia-site を開き、AGENTS.md と typing/README.md を読んでから作業してください。
みことばタイピングクエストに、ヨナ書のステージを1つ追加してください。
聖書は新改訳2017に合わせ、ふりがなを付けてください。
main には直接入れず、ブランチを作ってプルリクエストにしてください。説明は日本語で。
```

できたプルリクエストのURLを Claude に送れば、確認して取り込みます。

## 6. Gemini に頼むときのこつ

- 各ゲームの素材プロンプト集(Claude のドキュメント)をそのまま貼る
- キャラクターは同じ絵柄にするため、設定シートの絵を添付する
- 背景は白(光のエフェクトは黒)の単色、絵の中に文字は入れない
- できた絵・曲はドライブの「ゲーム制作(素材・管理) / <ゲーム名>」へ。ファイル名を素材管理表と合わせると取り違えが減ります
